Movie database key

Movie Vault pulls every movie ever released (over a million titles) from The Movie Database (TMDB). It needs a free key:

  1. Make a free account at themoviedb.org.
  2. Go to Settings → API and request a key (choose "Personal use").
  3. Copy the API Key or the API Read Access Token and paste it below.

The key stays on this device only.
